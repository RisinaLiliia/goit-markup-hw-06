# goit-markup-hw-06


This project is a responsive, one-page landing page designed as part of my coursework in frontend development. The goal of the project was to implement a layout that adapts seamlessly to various screen sizes using modern web development techniques. The page was built with attention to detail, ensuring a clean, responsive, and optimized user experience across all devices.

Project Overview
This project includes the layout and styling of a responsive web page. The design is based on the mockup provided in Figma, which can be found here.

Features
Responsive Layout: The layout adjusts smoothly to three key breakpoints (320px, 768px, 1158px), ensuring the page is fully responsive across all devices.
Mobile-First Approach: The design was created using the mobile-first approach, ensuring an optimized user experience on mobile devices.
Mobile Menu: A fully functional mobile menu that appears when toggled, designed for a seamless mobile browsing experience.
Key Technical Aspects
Layout
Horizontal Scroll Prevention: When viewing the page on any device with a width of 320px or more, no horizontal scrollbar appears.
Prettier Formatting: The source code is formatted using Prettier for consistent and clean code.
Image and Content Integrity: All images and text content are directly taken from the design mockup.
Modern Normalize: The modern-normalize style normalizer is integrated to ensure consistency across different browsers.
Code Guidelines: The code adheres to best practices and guidelines.
Responsiveness
Viewport Meta Tag: All pages include the viewport meta tag in the <head> block.
Three Breakpoints: The layout is designed with three main breakpoints: 320px, 768px, and 1158px.
Responsive Images: All background and content images are responsive and support screens with x1 and x2 density.
Min-Resolution Media Function: Used for responsive background images.
Mobile-First Styling: Media queries are written with a mobile-first approach using min-width for larger screen sizes.
Efficient Media Queries: Styles that are specific to certain screen widths are enclosed in precise media queries, eliminating unnecessary duplication of styles.
Mobile Menu
Complete Mobile Menu Layout: All elements of the mobile menu are properly marked up and styled.
Responsive Design: The mobile menu’s width corresponds to the layout specifications, and its height occupies the full viewport.
Visibility Toggle: The menu is initially hidden and can be shown by adding the is-open class to the menu element.
