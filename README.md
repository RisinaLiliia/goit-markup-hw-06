# goit-markup-hw-06

Perform layout of the adaptive version of all page elements

https://www.figma.com/design/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?node-id=297046-1554&p=f&t=dQsJYG7LoXGYYrAP-0

Criteria for accepting work by a mentor

Project

«A1» When viewing the page on any device with a width of 320px or more, a horizontal scroll bar does not appear.
«A2» The source code is formatted using Prettier.
«A3» All images and text content are taken from the layout.
«A4» The modern-normalize style normalizer is connected
«A5» The code is written in compliance with the guidelines.

Responsiveness

«B1» All pages have a viewport meta tag in the <head> block.
«B2» The layout is performed with respect to three breakpoints: 320px, 768px and 1158px.
«B3» All background and content bitmap images are responsive and support screens with a density of x1 and x2.
«B4» For responsive background images, the min-resolution media function was used.
«B5» When writing styles, the Mobile First approach and the min-width media function were used.
«B6» Styles that are only needed in a certain interval are enclosed in media queries (min-width: ) and (max-width: ) or only (max-width: ).
«B7» There is no unnecessary duplication of styles in media queries.

Mobile menu

«C1» All mobile menu elements are marked up.
«C2» All mobile menu elements are designed.
«C3» The menu width corresponds to the layout.
«C4» The menu height occupies the entire viewport.
«C5» The menu is initially hidden.
«C6» If you add the is-open class to the menu element, it appears.
